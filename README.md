# Dual Subs

Dual-language subtitle tracks generated on the Jellyfin server.

The plugin combines two existing **text** subtitle tracks from the same video into one
normal `.ass` file: the language being learned at the bottom, the native language above
it. Because the output is an ordinary external subtitle, every Jellyfin client shows it
without modifications: web, Android, Android TV, iOS, Swiftfin, Kodi, webOS and others.

Main use case: language learning with a familiar subtitle above and the target language
below.

## Requirements

- Jellyfin **12.0 or newer** (built against `Jellyfin.Controller` 12.1).
- .NET 10 to build from source.
- Source subtitles must be text based (SRT, ASS, SSA, VTT, mov_text, ...).
  Bitmap subtitles (PGS, VobSub, DVB) are skipped.
- At least one configured language pair.

## How it works

1. For every enabled pair, the plugin finds one text subtitle stream per language in the
   primary media source.
2. Forced and bitmap tracks are ignored, as are files written by this plugin.
3. Among the candidates it prefers non-SDH, then external, then the track with the most
   cues after parsing.
4. Jellyfin's `ISubtitleEncoder` converts each source to SRT with original timestamps.
5. The optional offset estimator aligns the secondary track.
6. The ASS file is uploaded through `ISubtitleManager.UploadSubtitle`, so Jellyfin stores
   it where the library says (next to the media or in the metadata folder) and refreshes
   the item.

The generated file starts with an ownership marker:

```ass
[Script Info]
; Generated by Jellyfin DualSubs
; DualSubs-Version: 1
; DualSubs-Pair: eng+spa
; DualSubs-SourceHash: ...
; DualSubs-OffsetMs: 0
Title: Dual ENG/SPA
```

Only files with that marker are ever replaced or deleted. If the source text or style
configuration changes and `OverwritePluginFiles` is enabled, the old plugin file is
deleted and regenerated. Otherwise generation is a no-op.

`SourceHash` is computed from the parsed cues (start, end and cleaned text), not from the
raw SRT bytes. Different extractor runs can format SRT differently even when the content
is identical; hashing canonical cues keeps generation idempotent. A render-version
constant is part of the style hash, so changing the ASS pipeline invalidates old files.

## Installation

### From the plugin repository

In Jellyfin go to **Dashboard → Plugins → Repositories**, click **+** and add:

```
https://github.com/undaniel/jellyfin-plugin-dualsubs/releases/latest/download/manifest.json
```

Then open the **Catalog** tab and install **Dual Subs**.

That URL always points at the manifest of the newest release, so Jellyfin shows updates
automatically. `manifest.json` in this repository mirrors the current release; the release
workflow (`.github/workflows/publish.yaml`) rebuilds the zip and the manifest with `jprm`
and attaches both to the GitHub release tagged `v<version>`.

### Manual build

```bash
dotnet build Jellyfin.Plugin.DualSubs.slnx
dotnet test Jellyfin.Plugin.DualSubs.slnx
```

To create the plugin zip:

```bash
python3 -m venv .venv
.venv/bin/pip install jprm
.venv/bin/jprm plugin build . -o artifacts
```

Copy `artifacts/dual-subs_<version>.zip` contents to a `DualSubs` folder
under the Jellyfin plugins directory and restart the server.

## Configuration

Open **Dashboard → Plugins → Dual Subs** and configure:

- **Language pairs**: learned language (bottom) and native language (top). Use ISO 639-1
  (`en`, `es`) or 639-2 (`eng`, `spa`) codes. The two languages must differ.
- **Layout**: `TopBottom` (native above, learned below) or `StackedBottom` (both at the
  bottom, native above the learned text).
- **Font sizes, colors, outline and italic**.
- **Auto-align offsets** with a maximum of 0–120 seconds.
- **Libraries**: no selection means every video library.
- **Automatic processing**: item added/updated events are queued and debounced.
- **Overwrite plugin files**: replace files whose source hash changed.

The **Run now** button starts the scheduled task `Generate dual subtitles`.

### StackedBottom approximation

The secondary `MarginV` is `PrimaryMarginV + round(PrimaryFontSize * 2.4)`, which leaves
room for up to two primary lines. Unusually long lines can still overlap.

## REST API

All endpoints require an administrator (`RequiresElevation`).

| Method | Route | Purpose |
|---|---|---|
| `POST` | `/DualSubs/Items/{itemId}/Generate` | Generate or regenerate all enabled pairs |
| `DELETE` | `/DualSubs/Items/{itemId}` | Delete only files generated by this plugin |
| `GET` | `/DualSubs/Items/{itemId}/Preview?pair=eng+spa` | Show tracks and offset without writing |

Example:

```bash
curl -X POST \
  -H "Authorization: MediaBrowser Token=\"$TOKEN\"" \
  "http://jellyfin:8096/DualSubs/Items/$ITEM_ID/Generate"
```

```json
{
  "itemId": "…",
  "results": [
    {
      "pair": "eng+spa",
      "status": "Created",
      "primaryStreamIndex": 3,
      "secondaryStreamIndex": 5,
      "offsetMs": 0,
      "message": null
    }
  ]
}
```

Statuses: `Created`, `Unchanged`, `Replaced`, `MissingSource`, `BitmapOnly`, `Error`.

## Limitations

- **Track title in clients**: Jellyfin names external subtitle files as
  `<video>.<language>.ass` and derives the visible title from that filename. The native
  upload API cannot set a custom title, so clients typically show **English** rather than
  **English - Dual ENG/SPA**. The file content is marked and managed correctly.
- Only the **primary media source** of a video is processed (no alternate versions).
- Two pairs with the same primary language upload files with the same base name; Jellyfin
  appends a numeric suffix. Both tracks still exist and are managed by content marker.
- `.strm` items are skipped.
- Bitmap-only tracks, forced tracks, empty tracks and tracks with zero parsable cues are
  not used.
- Offset estimation is a single constant shift, capped at 120 seconds. It does not handle
  drift that changes over time.
- Non-UTF-8 source SRTs rely on Jellyfin's encoder. Replacement characters are logged as
  warnings.
- Automatic events are debounced; a new episode is processed about one minute after it is
  indexed, not instantly.

## Development

Pure logic lives in `Jellyfin.Plugin.DualSubs/Core` and has no Jellyfin dependencies:

- `SrtParser`, `AssWriter`, `AssColor`, `OffsetEstimator`, `DualSubsStyleOptions`, `Cue`.

Verified Jellyfin 12.1 signatures and integration decisions are documented in
[`docs/api-notes.md`](docs/api-notes.md).

The test project covers the parser, ASS golden output, colors, offset estimator, source
selection and file marker. Run coverage with:

```bash
dotnet test --collect:"XPlat Code Coverage"
```

## Español

Genera pistas de subtítulos bilingües en el servidor a partir de dos pistas de texto que
ya existan en el vídeo: el idioma aprendido abajo y el nativo arriba. El resultado es un
`.ass` externo normal, así que funciona en todos los clientes de Jellyfin sin modificarlos.

Requisitos: Jellyfin 12 o superior, subtítulos de texto (los bitmap como PGS o VobSub se
omiten) y al menos un par configurado. Para instalarlo, añade
`https://github.com/undaniel/jellyfin-plugin-dualsubs/releases/latest/download/manifest.json`
en **Panel → Plugins → Repositorios** e instala **Dual Subs** desde el catálogo. Los pares
se configuran en **Panel → Plugins → Dual Subs**; también hay una tarea programada
«Generate dual subtitles» y una API REST para generar, previsualizar y borrar.

Limitaciones principales: solo se procesa la fuente de vídeo principal; los `.strm` se
omiten; el título visible del cliente suele ser solo el idioma («English») porque la API
nativa de subida no permite un nombre personalizado; y la alineación automática aplica un
único desplazamiento constante.
